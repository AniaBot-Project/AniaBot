# Web 控制面板地图

面板是 Bot 的内置管理后台（Vue 3 SPA，`go:embed` 进二进制），默认地址 `http://127.0.0.1:7700`，地址由 `bot.admin_panel.listen` 决定。前端用 hash 路由，具体页面形如 `http://127.0.0.1:7700/#/config`。

## 一、登录与账号

- 首次启动会在**控制台**打印一次性随机初始密码（同时写进日志）。登录后点侧边栏「修改密码」可改（新密码至少 6 位，改完所有会话失效需重新登录）。
- 会话 Cookie `ania_session`，24 小时滑动过期。
- 登录失败有防爆破锁定。
- **忘记密码**：停掉 Bot，执行 `./AniaBot -set-password 新密码`（只重置密码并退出，不启动 Bot），再正常启动。
- 面板关掉了（`bot.admin_panel.enable=false`）：用环境变量 `ANIA_BOT_ADMIN_PANEL_ENABLE=true` 临时拉起，改回来再正常启动。

## 二、首次设置向导

首次启动时 `meta.setup_pending` 为真，面板会强制进入设置向导，**此时平台适配器完全不连接**（避免控制台刷重连日志），填完向导并重启后才开始连。向导收集：平台连接信息、管理员 ID、AI 模型配置。完成后标记 `meta.setup_pending=false`（该键是内部标记，AI 的 `config_set` 不允许写）。

> 排查「Bot 起来了但 QQ/飞书一直不在线」时，先确认向导是否完成。

## 三、页面清单（侧边栏按用途分 5 组）

侧边栏按用途分组：**总览**（状态总览、Token 用量）、**对话**（试聊室、会话上下文）、**日志**（控制台日志、消息与操作日志、AI 运行记录）、**AI 能力**（AI 定时任务、记忆与知识库、技能管理、Agent 团队）、**系统**（配置管理、通讯录、插件市场、自动更新）。一组里有多个页面时，侧边栏只占一个入口，页面顶部用页签切换；子页面各自有独立路由，`#/...` 旧链接、书签与深链（`?task=` / `?task_id=`）都继续可用。

### 总览

| 页面 | 路由 | 能做什么 |
| --- | --- | --- |
| 状态总览 | `/#/` | 运行时长、goroutine 数、适配器连接状态、已加载插件与版本、主机 CPU/内存、API 余额（开启 `bot.balance.enable` 时） |
| Token 用量 | `/#/tokenstats`（用量统计）· `/#/quota`（配额限制） | 用量统计：按来源/会话统计 token 消耗与趋势；配额限制：查看当日会话/全局配额消耗并可重置（需先开 `plugin.ai_chat_bot.quota.enable`） |

### 对话

| 页面 | 路由 | 能做什么 |
| --- | --- | --- |
| 试聊室 | `/#/chatconsole` | 在面板里直接和 AI 对话测试，复用真实管线（提示词/记忆/知识库/工具），可选绑定某个群/私聊继承配置；回复只回显面板、不发到平台，计入「对话记录」与 Token 用量（不占配额） |
| 会话上下文 | `/#/contexts` | 查看每个会话（群聊/私聊）AI 真正持有的完整上下文：系统提示词三段（静态提示词 + 技能表 + 场景描述）、消息历史（含工具调用、工具结果、推理内容）与工具定义，带字符数与 token 估算、最近一次请求的 prompt token 与上下文上限占比；可清空单个/多个/全部会话的上下文、删除某个会话，或导出单个/多个/全部会话的完整上下文（JSON）。会话正在执行请求时，清空/删除会先弹确认框，确认后先终止请求再生效 |

### 日志

| 页面 | 路由 | 能做什么 |
| --- | --- | --- |
| 控制台日志 | `/#/console` | 实时看进程日志（slog + 标准 log），**纯内存环形缓冲（约 2000 条），重启后清空** |
| 消息与操作日志 | `/#/msglogs`（消息日志）· `/#/oplogs`（操作日志） | 消息日志：聊天式记录全部进出消息（按群聊/私聊/系统通知分会话，含合并转发、图片预览、文件下载、Bot 自己发出的消息）；操作日志：面板与 AI 的动作审计（改配置、重启、安装插件、AI 改配置等），SQL 表 `ania_op_log` |
| AI 运行记录 | `/#/querylogs`（对话记录）· `/#/agent-tasks`（后台任务） | 对话记录：每次 AI 请求的完整执行过程（触发、工具调用、token、最终输出；含主动互动与试聊），可筛选、导出 JSON、清除；普通对话记录带停止原因（异常结束在列表标出，详情可看完整值）与历史关联任务 ID（可跳转后台任务页签），也可从后台任务页签按 `?task_id=` 反查。后台任务：查看 AI 后台任务注册表最近 100 条（`GET /api/agent-tasks?limit=1~500`，返回 `parent_id` 与 `prompt`）：运行中/等待/完成/失败统计，按状态、类型（子代理/交接/后台工作流/追问/团队任务/团队运行/团队成员）与关键词筛选；普通回合不写入任务表、也不在任务页签展示（完整过程看对话记录，历史 `turn` 行不返回）。表格展示任务 ID/类型/状态/标题/会话/token/耗时/更新时间/停止原因，**点击行弹出详情**（任务指令、结果、错误与结构化信息：团队运行的成员摘要；团队成员/子代理的工具调用步骤，执行中按约 3 秒增量刷新并标注「执行中，已完成 N 步」，不必等跑完；任务指令/结果/错误/工具参数与结果都完整保存、不截断，前端折叠展示）；详情里可沿父任务 / 追问与子任务（含团队成员）跳转，串起整条追问链。支持按当前筛选条件导出 JSON（`GET /api/agent-tasks/export`）与清除已结束记录（`DELETE /api/agent-tasks`，运行中/排队中的任务保留）；页签支持 `?task=` 深链定位；下方另列进行中的长任务目标（`GET /api/agent-goals`）。自动刷新默认开（10 秒） |

### AI 能力

| 页面 | 路由 | 能做什么 |
| --- | --- | --- |
| AI 定时任务 | `/#/tasklogs` | 查看 AI 定时任务清单与每次执行记录（触发内容、结果、是否跳过推送），支持导出/清除 |
| 记忆与知识库 | `/#/memory`（长期记忆）· `/#/knowledge`（知识库） | 长期记忆：按 scope（`g:群ID` / `f:用户ID`）查看、新增、修改、删除长期记忆，可勾选多条批量删除；知识库：按 scope 管理知识库文档（新增、编辑、勾选多篇批量删除） |
| 技能管理 | `/#/skills` | 上传/删除外置技能、启用或禁用（内置技能显示为内置，不可删不可禁）、查看 SKILL.md 与附属文件 |
| Agent 团队 | `/#/team` | 管理跨会话共享的全局团队（成员 = 名称 + 角色提示词），供 AI 的 `team_run` 引用 |

### 系统

| 页面 | 路由 | 能做什么 |
| --- | --- | --- |
| 配置管理 | `/#/config`（参数配置）· `/#/files`（扩展配置） | 参数配置：按分组动态渲染全部配置项、保存；导出完整配置 JSON；配置预设（快照保存/一键应用/删除）。扩展配置：四份 JSON 的可视化表单 + 源码模式：`mcp` / `prompt` / `hooks` / `commands` |
| 通讯录 | `/#/contacts` | 多平台群/好友列表（依赖适配器实现 `ContactsExt`，QQ 官方等平台不支持） |
| 插件市场 | `/#/marketplace` | 浏览 AniaBot-Plugins 仓库插件，在线安装/升级/卸载/回滚，安装后自动编译并重启（容器内也开箱可用） |
| 自动更新 | `/#/update` | 从 git 拉取最新代码、编译并自动重启；需先配 `bot.update.source_dir`（`go run` 开发模式下禁用） |

**外观设置**（`/#/appearance`）：面板外观——主题色（预设色板 + 任意取色）、配色方案（页面底色 + 卡片纸张/描边/文字色）、背景纹理、侧栏风格、圆角、动效，另有 6 套预设主题一键切换；**偏好只存在当前浏览器（localStorage 键 `aniabot.appearance.v1`），即时生效，不写 Bot 配置、不需要重启，也不影响其他人的浏览器**。

侧边栏底部还有：GitHub 仓库链接、**外观设置**（`/#/appearance`，只在这里，导航列表里不重复）、**重启 Bot**（等于管理员 `/reboot`，会等新进程起来后自动刷新页面）、修改密码、退出登录。

## 四、常见面板操作

- **改配置并让它生效**：配置管理 → 参数配置 → 改 → 保存 → 点侧边栏「重启 Bot」（或管理员在会话里发 `/reboot`）。面板会提示哪些改动需要重启。
- **备份配置**：配置管理 → 参数配置 → 「导出 JSON」（含密钥等敏感值，注意保管）；或「配置预设」把当前配置存成命名快照，之后一键回切（应用预设后仍需重启）。
- **加一个 MCP 服务器**：配置管理 → 扩展配置 → `mcp` → 表单逐项填（名字、传输方式 stdio/streamable/sse、命令或端点、参数、环境变量、请求头、超时）→ 保存 → 重启。也可以切到源码模式直接改 JSON。
- **给某个群换人设**：配置管理 → 扩展配置 → `prompt` → 按 `{"groups": {"qq:群号": "提示词"}}` 填 → 保存，**数秒后自动生效**，不用重启。
- **加自定义命令**：配置管理 → 扩展配置 → `commands`（或会话里 `/cmd add 名字 模板`）→ 数秒后生效；`$args` 是参数占位符。
- **装插件**：插件市场 → 选插件 → 安装 → 等编译重启完成（面板有进度）；出问题可用「回滚」。
- **看某个群/某人的 AI 消耗**：AI 运行记录 → 对话记录按会话筛选，或 Token 用量 → 用量统计。
- **看 AI 到底收到了什么上下文**：会话上下文 → 选会话。系统提示词、历史消息、工具定义与 token 估算都在一页里；「实时上下文」是驻留内存的当前消息窗口，「持久化快照」说明会话未驻留或正在执行请求。记忆/知识库/待办等每轮注入只作用于当轮请求，不在快照里。
- **让 AI 忘掉某个会话**：会话上下文 → 选会话 → 「清空上下文」（保留会话，下次发言即新对话）；要连会话级状态（长任务目标、计划模式）一起清掉就用「删除会话」。会话正在执行请求时会先确认是否终止请求。
- **备份/对比上下文**：会话上下文 → 勾选多个会话 → 「导出」，或右上角「导出全部」；导出的 JSON 结构与详情页一致，可用于离线对比上下文结构。
- **换面板颜色/侧栏风格**：外观设置 → 选预设主题，或单独挑主题色、页面底色、纹理、侧栏、圆角；即时生效、不用重启。偏好存在浏览器本地，换个浏览器看到的是默认外观。
- **验证平台连接**：状态总览的适配器状态（如 `qq · 已连接 / feishu · 重连中`），失败原因也会显示。

## 五、部署注意

- 面板默认只监听 `127.0.0.1`。要让别人访问改 `bot.admin_panel.listen=0.0.0.0:7700`（重启生效），并自行用防火墙/反代限制来源。
- 面板是 SPA + hash 路由：反向代理只需把 `/` 和后端 API 一起转发到该端口，`/#/xxx` 不需要服务端路由支持。若用 HTTPS 反代，注意 WebSocket 不需要（面板无 ws）。
- 面板与 Bot 同进程：面板不可达通常意味着进程没起来、端口被占或监听地址只绑了回环。
- 在线 Demo（只读演示数据，不连真实 Bot）：docs 站点的 `/demo/`。
